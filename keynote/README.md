# Keynote material

`qr-join-process-science-org.svg` encodes `https://process-science.org/join/`.
It was generated at error correction level H, the most robust level, and decoded
back to that URL to check it before committing.

Use the `.svg` in the slide deck: it stays sharp at any projector resolution.
The `.png` is there for tools that will not take SVG.

Put the URL on the slide as readable text next to the code as well
(`process-science.org/join`). Some people in the room will not scan anything,
and if the projector washes the code out, the text is the only way in.

phone that is **not** on the university network, and check that the form loads
